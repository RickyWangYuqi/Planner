# Planer 日程便签

小而美的 **Windows 桌面日程记录便签**。本地优先、自动保存、启动即用。

- 技术栈：**Tauri 2 + React 18 + TypeScript + Vite**
- 打包体积：安装包约 1~2 MB，运行内存占用低
- 数据：保存在本地 `%APPDATA%\com.planer.app\data.json`，每次变更自动保存

## 功能一览

### 日程
- 当日日程 / 未来日程
- 未来日程采用**「起始日期-截止日期」区间**：起始日期可不填（默认从创建日的下一天开始）；列表显示如「8月25日-9月1日」；拖动到当日/再拖回时保留整个区间
- 日期滚动：当日未完成日程次日自动顺延；未来日程在截止日期当天自动移入当日列表末尾
- **「选择日期」按钮**：可切换到今天或未来的任意日期查看、编辑日程（日历上起始/截止日期会打点提示）
  - 切换到未来：截止日期 ≤ 该日的未来日程自动移入当日
  - 切换回今天：隐藏截止日期更晚的任务自动放回未来列表
- 添加/编辑未来日程时**两个日历内联显示**，可直接点选起止日期
- 启动时显示加载状态，数据加载完成后立即展示已有日程（本地读取仅数毫秒，IO 不阻塞界面）
- 打钩完成：当日已完成日程显示为灰色删除线，次日自动进入历史；未来日程打钩后立即归档进历史
- **完成后自动定位下一项**（默认关，可在设置中开启）：当完成的正是当日第一个未完成日程时，完成后自动平滑滚动，把下一个未完成日程置于列表顶部；该位置会保存，下次启动仍按此位置定位；关闭开关会清空定位
  - 取消打钩、编辑、增删日程都不会误触发滚动，只在锚点变化或打开页面时定位一次
- **完成百分比**：编辑日程时可设 0-100% 或「未设置」；设置后行内显示迷你进度条与百分比
  - 打钩完成视为 100%；把已完成日程改到 100% 以下会自动取消打钩
  - 设置项「未设进度默认显示 0%」可开关（默认关：只显示已设置进度的日程）
- **拖动排序**：长按拖拽即可排序；当日 ⇄ 未来可跨区拖动
  - 拖动时在目标位置展开淡色圆角空槽，相邻卡片平滑让位，便于看清将插入哪两项之间；保留浮卡的倾斜、阴影与跟手效果，提示不覆盖文字
  - 指针停留在空槽内时保持落点稳定；松手后按预览排序，取消拖动或窗口失焦会恢复原布局
  - 当日 → 未来：弹窗设置时间区间（若带隐藏起止时间则自动填入，可修改）
  - 未来 → 当日：保留起止区间但当日不显示；再拖回未来时自动沿用
- 编辑：当日日程可改名称、分组与完成进度（隐藏起止时间不可改）；未来日程可改名称、分组、起止日期与进度；**点击整行不会打开编辑弹窗，请点「编辑」按钮**
- 自动编号：当日 / 未来各自从 1 编号，可在设置中开关，拖动后自动重排
- **分组**（默认关，可在设置中开启）：新增或编辑当日、未来日程时，均可选择已有分组或新建分组；也可再次点选已选分组移回「未分组」
  - 分组选择位于日程内容下方，标签文字居中，以高亮底色表示选中；点击「新建分组」时输入框和按钮平滑展开，取消时平滑收起。输入名称后，点击「创建并选中」或按回车，新分组标签平滑淡入、相邻标签让位，并给出明确的已选提示
  - 同名分组会直接选用；分组选择随日程一起保存，尚未提交的新分组仅作为当前窗口的草稿，取消新增或编辑不会保存这些草稿
  - 已保存的分组会一直保留在新增、编辑日程的分组标签中；即使全部日程移入其他组，重新打开窗口或重启应用后仍可选用，只有主动删除分组才会移除标签
  - 长按分组标签可进入删除状态：淡红边框、轻微抖动，右上角出现灰底白色叉号，并提示「再次点击分组标签可取消删除」；点击叉号后标签平滑缩小淡出，相邻标签自动补位。「未分组」不可删除；再次点击该标签、点击其它位置或按 Esc 可退出删除状态
  - 在新增或编辑窗口删除已有分组会立即生效，当日和未来属于该组的日程均移入各自的「未分组」；不会删除日程，取消窗口也不会撤销这次删除。删除尚未保存的新分组只移除当前窗口里的草稿标签
  - 开启后按分组分区显示，未分组的日程归入「未分组」
  - 分组标题可按住拖动，把整组搬到其它分组之前，快速调整分组顺序；悬停标题右侧出现删除按钮
  - 删除分组不会删除日程：组内日程全部移到「未分组」末尾
  - 跨组拖动排序会把日程同时改到落点所属分组；关闭分组功能时只排序、不改动也不展示分组信息
- **当日 / 未来分区可拖动分割线**：上下拖动两个列表之间的分割线调整区域高度比例，比例自动保存（默认当日区约占 45%）

### 历史日程（设置 → 历史日程）
- 按日期分组存放已完成的日程，类似回收站
- 恢复：原计划日期为今天 → 直接回到当日；已过 → 弹窗选择恢复到今天或未来日期
- 永久删除（二次确认）、一键清空历史

### 日程显示设置（全部可在设置中开关）
| 功能 | 默认 |
| --- | --- |
| 自动编号（当日 / 未来各自从 1 编号） | 开 |
| 未设进度默认显示 0%（未设置的日程也显示 0% 进度条） | 关 |
| 完成后自动定位下一项（把下一个未完成日程滚到顶部，并记住位置） | 关 |
| 按分组显示日程（关闭仅隐藏，不删除已设置的分组信息） | 关 |

### 窗口行为（全部可在设置中开关）
| 功能 | 默认 |
| --- | --- |
| 窗口置顶 | 关 |
| 全屏自动隐藏（检测任意应用全屏，如视频/游戏） | 关 |
| 失去焦点自动缩小为小卡片，悬浮展开（流畅非线性动画）、点击保持 | 关 |
| 关闭窗口：退出程序 / 最小化到系统托盘 | 退出程序 |
| 开机启动 | 关 |

- **窗口大小可自由调整**：右下角拖拽手柄或系统边缘调整（最小 380×520），布局自适应不重叠；缩小/展开后会记住你的自定义尺寸；**调整大小过程中不会误触发缩小**
- 缩小功能仅在主页面生效（进入设置/历史页不会缩小）；**拖动窗口、调整大小时不会误触发缩小，移动结束后失焦缩小立即生效**
- 缩小卡片为紧凑尺寸，仅显示「8月24日日程」；悬浮展开时不带左右滑动动画（淡入恢复）
- 系统托盘常驻：左键单击显示/隐藏，右键菜单含「显示主窗口 / 隐藏窗口 / 退出程序」

### 外观与页面
- 主题模式：浅色 / 深色 / 跟随系统
- 四套配色预设（每套含浅色与深色版本）：海盐 / 森林 / 日落 / 墨影
- 主界面 / 设置 / 历史三个页面之间**左右滑动过渡动画**，各页滚动位置独立记忆
- 应用内圆角元素（列表、按钮、弹窗等），窗口四周铺满

## 开发

环境要求：**Node.js ≥ 22**（本机验证 v24.20.0 LTS）+ npm（随 Node 自带，Node 24 对应 npm 11）

```bash
# 安装依赖
npm install

# 前端开发（配合 src-tauri 目录）
npm run tauri dev

# 构建发布版（生成 dist 与 src-tauri/target/release，含 NSIS 安装包）
npm run tauri build
```

安装包输出：`src-tauri/target/release/bundle/nsis/Planer_1.0.0_x64-setup.exe`
绿色版可执行文件：`src-tauri/target/release/Planer.exe`

## 使用提示

- 「失去焦点自动缩小」建议同时开启「窗口置顶」，否则小卡片可能被其它窗口遮挡
- 缩小卡片显示「8月24日日程」：悬浮自动展开；点击后保持展开；期间未点击移开鼠标会再次缩小
- 关闭窗口行为选择「最小化到系统托盘」后，点右上角 × 不会退出，程序驻留托盘
- 开机启动默认以最小化到托盘方式启动
