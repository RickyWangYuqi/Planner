# Planer 日程便签

小而美的 **Windows 桌面日程记录便签**。本地优先、自动保存、启动即用。

- 技术栈：**Tauri 2 + React 18 + TypeScript + Vite**
- 打包体积：安装包约 1~2 MB，运行内存占用低
- 数据：保存在本地 `%APPDATA%\com.planer.app\data.json`，每次变更自动保存

## 功能一览

### 日程
- 当日日程 / 未来日程（未来日程带截止日期）
- 日期滚动：当日未完成日程次日自动顺延；未来日程在截止日期当天自动移入当日列表末尾
- **「选择日期」按钮**：可切换到今天或未来的任意日期查看、编辑日程（日历上有日程的日期会打点提示）
  - 切换到未来：截止日期 ≤ 该日的未来日程自动移入当日
  - 切换回今天：隐藏截止日期更晚的任务自动放回未来列表
- 添加未来日程时**日历内联显示**，可直接点选截止日期
- 启动时显示加载状态，数据加载完成后立即展示已有日程（本地读取仅数毫秒，IO 不阻塞界面）
- 打钩完成：当日已完成日程显示为灰色删除线，次日自动进入历史；未来日程打钩后立即归档进历史
- **拖动排序**：长按拖拽即可排序；当日 ⇄ 未来可跨区拖动
  - 当日 → 未来：弹窗设置截止日期（若带隐藏截止时间则自动填入，可修改）
  - 未来 → 当日：保留截止时间但当日不显示；再拖回未来时自动沿用
- 编辑：当日日程只能改名称；未来日程可改名称与截止日期
- 自动编号：当日 / 未来各自从 1 编号，可在设置中开关，拖动后自动重排

### 历史日程（设置 → 历史日程）
- 按日期分组存放已完成的日程，类似回收站
- 恢复：原计划日期为今天 → 直接回到当日；已过 → 弹窗选择恢复到今天或未来日期
- 永久删除（二次确认）、一键清空历史

### 窗口行为（全部可在设置中开关）
| 功能 | 默认 |
| --- | --- |
| 窗口置顶 | 关 |
| 全屏自动隐藏（检测任意应用全屏，如视频/游戏） | 关 |
| 失去焦点自动缩小为小卡片，悬浮展开（流畅非线性动画）、点击保持 | 关 |
| 关闭窗口：退出程序 / 最小化到系统托盘 | 退出程序 |
| 开机启动 | 关 |

- **窗口大小可自由调整**：右下角拖拽手柄或系统边缘调整（最小 380×520），布局自适应不重叠；缩小/展开后会记住你的自定义尺寸；**调整大小过程中不会误触发缩小**
- 缩小功能仅在主页面生效（进入设置/历史页不会缩小）；**拖动窗口、调整大小时不会误触发缩小，移动结束后失焦缩小立即生效**
- 缩小卡片为紧凑尺寸，仅显示「8月24日日程」；悬浮展开时不带左右滑动动画（淡入恢复）
- 系统托盘常驻：左键单击显示/隐藏，右键菜单含「显示主窗口 / 隐藏窗口 / 退出程序」

### 外观与页面
- 主题模式：浅色 / 深色 / 跟随系统
- 四套配色预设（每套含浅色与深色版本）：海盐 / 森林 / 日落 / 墨影
- 主界面 / 设置 / 历史三个页面之间**左右滑动过渡动画**，各页滚动位置独立记忆
- 应用内圆角元素（列表、按钮、弹窗等），窗口四周铺满

## 开发

```bash
# 安装依赖
npm install

# 前端开发（配合 src-tauri 目录）
npm run tauri dev

# 构建发布版（生成 dist 与 src-tauri/target/release，含 NSIS 安装包）
npm run tauri build
```

安装包输出：`src-tauri/target/release/bundle/nsis/Planer_1.0.0_x64-setup.exe`
绿色版可执行文件：`src-tauri/target/release/Planer.exe`

## 使用提示

- 「失去焦点自动缩小」建议同时开启「窗口置顶」，否则小卡片可能被其它窗口遮挡
- 缩小卡片显示「8月24日日程」：悬浮自动展开；点击后保持展开；期间未点击移开鼠标会再次缩小
- 关闭窗口行为选择「最小化到系统托盘」后，点右上角 × 不会退出，程序驻留托盘
- 开机启动默认以最小化到托盘方式启动
